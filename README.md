# Roots Foundation — Next.js starter

Basic Next.js starter configured with Tailwind CSS and the Poppins font.

Getting started

```bash
cd /Users/mach/Desktop/roots
npm install
npm run dev
```

Files of interest

- [app/layout.js](app/layout.js) — global layout (App Router)
- [app/page.js](app/page.js) — starter homepage (App Router)
- [styles/globals.css](styles/globals.css) — Tailwind + Poppins setup
- [tailwind.config.js](tailwind.config.js) — Tailwind configuration
